3. Бросьте в тигли что-нибудь дешёвое (палки, грязь, брёвна) — Vis накопится сам.
4. ПКМ по инфьюзеру — откроется окно с 3×3 сеткой.
5. Положите ингредиенты по рецепту инфьюзера (см. книгу рецептов).
6. Закройте GUI. Раз в секунду будет проверяться сетка, и если рецепт совпал — из блока полетят лучи к тиглям, Vis спишется, а результат выпадет на блок.

⚠️ **Не кладите предметы стаками > 1** в сетку — блок взорвётся. Это защита от дюпов.

### Recipe Book

1. Поставьте книжную полку.
2. Возьмите в руку редстоун.
3. ПКМ по полке — появится книга с рецептами.
4. Возьмите книгу, ПКМ ею в воздухе — в чате постранично отобразятся все рецепты.

## Конфигурация

Файл `config/ThaumCraft.cfg` управляет ID блоков и предметов мода. Если ID занят — мод автоматически сдвинет его на +1 и попросит перезапустить игру. Один и тот же конфиг должен быть **и на сервере, и на клиенте**, иначе предметы не совпадут.
